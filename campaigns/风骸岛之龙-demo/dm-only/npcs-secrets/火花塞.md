## 真实身份
**蓝龙雏龙**（中型龙类，守序邪恶，CR3）。是茹娜拉一百年前在 D5 杀的那条蓝龙的**后裔**。

数据块：06_附录B_生物图鉴.md p75（蓝龙雏龙）（路径 `docs/modules/风骸岛之龙/06_附录B_生物图鉴.md`，需自备模组数据）
- HP 52
- AC 17
- **闪电吐息** 4d10 闪电（30×5ft 线，DC12 敏捷豁免，半伤）充能 5~6
- **多重攻击**：啃咬（+5，1d10+3 穿刺 + 1d4 闪电） + 双爪（+5，1d6+3 抓挠）
- 速度 30ft / 60ft 飞行
- 感官：盲视 10ft、黑暗视觉 60ft、被动察觉 14
- 免疫闪电；语言：龙语、通用语

## 真实动机
**复制祖先野心**：掌控岛上巨龙残魂的魔法（金属龙 + 色彩龙战死的魔法外溢），发动一场可以**驱使死龙意志**的仪式。

## 仪式细节
- **场地**：D2 圆顶大厅（米克米恩在此制雕塑）
- **祭品**：艾德隆（青铜龙雏龙，囚禁于 D6）
- **触发条件**："弑王星"彗星最近时（DM 自定具体时点；推荐：玩家长休 ≥ 3 次自动触发）
- **机制**（备用高潮 E4-06 启动时）：
  - 火花塞主敌（满血状态）+ 任何幸存狗头人 / 带翼狗头人
  - **龙的精魄表**：每轮战斗末（先攻 0）骰 d10 触发随机效果（见 [dm-notes.md](../dm-notes.md) 末尾的精魄表）
  - **干扰雕塑**：第一次攻击 / 破坏雕塑 → 火花塞分心，攻击 / 豁免劣势直到他下回合末

## D5 战斗细节（首选关卡）
- 火花塞睡在水晶旁（东北角）
- **潜行**：一半角色 DC14 敏捷（隐匿）成功 = 不惊醒
- **外交**：说龙语角色可干扰他演讲（成功阻止他第一回合攻击）；但提到茹娜拉 / 艾德隆 = **立即开战**
- **战斗节奏**：
  - 第一回合用吐息 + "遮蔽"（PHB 战斗篇规则）
  - 每回合可发表蓝龙傲慢台词
  - HP < 25% 时不撤退（自负不逃；模组明示）
- **逃跑**：火花塞不追，会嘲弄（"你以为这样就能阻止我？"）

## 战斗后宝藏
- 大堆铜银金币（折合 ~25 gp）
- 粗制长笛
- 闪光沙沙袋
- 其他他喜欢的小玩意

## 与剧情的关系
- 是主线 BBEG
- 玩家可以选择：
  - **杀死他**（标准胜利）
  - **击退他**（他逃 → 备用高潮 E4-06 在 D2 发动仪式）
  - **不打他**直接救艾德隆（D6 解链 + 离开 → 仪式启动 → 必有备用高潮）

## DM 笔记
- 台词风格：**傲慢 / 蓝龙特征**（讽刺 / 阴谋家口吻）
  - "这岛是我祖先的，回到我手中是天经地义"
  - "茹娜拉？那头老青铜龙？她杀了我祖父，今天她的孩子也要为此付出代价"
- 他**不主动追击**逃跑的玩家（自负，认为他们不会真敢回来）
- 如果玩家用龙语对话 + 提到祖先/茹娜拉/艾德隆 → 他立即愤怒攻击（不再外交）
- **首选玩家以正面战斗胜利**——杀火花塞 = 模组完美结局
- 风格执行：黑暗向 → 火花塞更冷酷无情，仪式氛围浓重；粉红向 → 火花塞可有"被爱左右"的悲剧动机（祖父被杀的家族复仇），允许玩家最后一秒说服他放弃（高难，DC20+ 说服）
